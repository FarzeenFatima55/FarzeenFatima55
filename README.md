### 🔨 Featured Projects

**[Silent Witness](https://github.com/FarzeenFatima55)** — Privacy-first web app helping cyber harassment victims in Pakistan document evidence & generate PECA 2016-aligned NCCIA complaint drafts. Built with Next.js 14, Supabase (RLS + pgcrypto), Tesseract.js OCR, Groq/Llama & jsPDF.

**GetHired AI** — Job application agent with resume parsing, JD matching, tailored resume generation (before/after diff view), and application tracking. Next.js, Supabase, Claude API.

**DeadlineCopilot** — AI productivity app with a flat, Linear/Notion-inspired UI, Firebase + Gemini + Google Calendar integration.

**EatBot** — SaaS restaurant onboarding platform with WhatsApp/Instagram chatbot automation. Next.js 14 + Tailwind + Framer Motion.

**University Room & Timetable Manager** — Real-time room-change notification system built with Next.js 14, Firebase (Google Workspace auth), and a custom PDF-to-CSV timetable parser.
